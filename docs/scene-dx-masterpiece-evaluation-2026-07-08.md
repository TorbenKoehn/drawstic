# Scene-DX Masterpiece Evaluation - Large-Canvas Rebuild (2026-07-08)

This third scene run raised ambition: larger canvases, richer composition, masks, 2D/3D-style transforms, and more complete use of the feature palette. The scoring scale uses 1.0 as best and higher numbers as worse.

## Summary

Overall grade improved from 1.7 to 1.6. Larger canvases improved material readability and scene density, while the main remaining weakness shifted from language mechanics to craft discipline: composition planning, controlled detail, and verification.

## Coverage

| Scene | Focus | Outcome |
|---|---|---|
| Arctic | scale, atmosphere, value grouping | strong |
| Desert | dunes, heat, shape rhythm | strong |
| Island | foliage, water, layered depth | strong |
| Market | density, props, architecture | hardest case |
| Orbit | curves, rings, glow, orbital depth | strongest transform case |
| Reef | organic forms and colour | improved |
| Volcano | lava, smoke, local light | strong |

## Main Findings

1. Large canvases reward a strong silhouette-first plan; detail should follow structure, not replace it.
2. Masks and transforms worked well enough for ambitious scenes, but examples must show where they are worth the token cost.
3. Lighting improvements held up under heavier scenes.
4. The best outputs used deliberate layer order: background, atmosphere, terrain, contact shadows, subjects, highlights, then final texture.
5. Visual verification remains mandatory because structural checks cannot judge balance, focal hierarchy, or over-detail.

## Craft Rules Distilled

- Start with the largest readable masses.
- Lock a single light contract early.
- Use masks for meaningful occlusion or containment, not decoration.
- Use transforms where reuse is real and visual artifacts are acceptable.
- Verify at native size before polishing @4 renders.

## Follow-Up Actions

- Keep `scene-craft.md` focused on layer order, lighting contracts, and proof renders.
- Prefer compact examples that demonstrate why a feature matters.
- Add future tooling only where repeated manual verification is slow or error-prone.
